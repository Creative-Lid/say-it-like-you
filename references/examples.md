# Examples

Use these for calibration, not as templates to copy.

## Clear professional

Before:

> We are excited to announce the launch of our revolutionary new reporting experience, designed to empower teams to unlock actionable insights.

After:

> The new reporting view puts trends, filters, and exports on one screen. Teams can find the number they need without rebuilding the same report three times.

## Dry professional

Before:

> Our seamless integration streamlines your workflow and eliminates manual data entry.

After:

> New orders appear in the accounting system automatically. Nobody has to spend Friday afternoon copying invoice numbers between tabs, which was not exactly anyone's career plan.

## Approachable expert

Before:

> Great question! OAuth can seem intimidating, but don't worry. Let's dive into the three key concepts you need to know.

After:

> OAuth lets someone approve limited access without giving your app their password. Start with three pieces: the client, the authorization server, and the access token.

## Sharp operator

Before:

> To be clear, this is not merely a performance optimization. It is a fundamental architectural improvement that will transform how the system scales.

After:

> Cache the account lookup. It runs on every request and currently accounts for most of the database traffic.

## Reply with shared context

Before:

> You're right that the import failed because the CSV has two columns named `email`. To recap, the file came from the old member system and includes duplicate headers. We should rename the second column and run the import again.

After:

> Rename the second `email` column, then run the import again. The importer treats duplicate headers as the same field.

## Sensitive support reply

Before:

> Oops! It looks like your changes went on a little adventure. Don't worry, our rockstar support team is here to help!

After:

> Your changes were not saved. We have the error report and are checking whether the draft can be recovered. Please leave this page open while we investigate.
